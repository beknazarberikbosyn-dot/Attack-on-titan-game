# Свои спрайты титанов

Картинки из этой папки заменяют процедурных титанов игры.

1. Нарисуй титана видом спереди (Piskel, Aseprite, LibreSprite…), фон прозрачный, ступни у нижнего края.
2. Экспортируй PNG сюда, например `armored.png`.
3. Добавь строку в `manifest.js`:
   ```js
   armored: { base: 'armored.png', legsFrom: 0.5 },
   ```
   `legsFrom` — на какой доле высоты сверху начинаются ноги (нужно для автоанимации шага).

Размер картинки любой — игра сама подгонит рост (Колоссальный 60 м, Бронированный 15 м и т.д.).

**Анимация.** Из одного кадра игра сама собирает ходьбу (ноги шагают по очереди, корпус покачивается)
и замах. Если хочешь свою анимацию — нарисуй кадры и укажи их:
```js
colossal: { base: 'colossal.png', walk1: 'colossal_walk1.png', walk2: 'colossal_walk2.png', attack: 'colossal_attack.png' },
```
Пар, вспышки от ударов, исчезновение при смерти и другие эффекты накладываются поверх автоматически.

Исходники в Piskel лежат в `src/` — их можно открыть в piskelapp.com и дорисовать.
Типы: `colossal`, `armored`, `female`, `beast`, `jaw`, `normal`, `small`, `deviant`, `eren`.
