# Картинки для карточек

Положи сюда изображения персонажей — игра подхватит их сама и **автоматически превратит в пиксель-арт** (48×40).
Можно и без файлов: перетащи картинку прямо на карточку в игре — она сохранится в твоём браузере.
Имя файла = id карточки, формат `.png`, `.jpg` или `.webp`.

|---|---|

| `scouts.png` | Отряд разведкорпуса |
| `armin.png` | Армин Арлерт |
| `connie.png` | Конни Спрингер |

| `eren.png` | Эрен Йегер |

| `levi.png` | Леви Аккерман |

Картинка обрезается по центру под окошко карточки (примерно 96×78), поэтому лучше
брать портрет, где лицо в центре. Пока файла нет — на карточке рисуется пиксельный значок с инициалами.

Если выкладываешь сайт публично, бери картинки, которые разрешено использовать (официальные материалы
обычно защищены авторским правом).
